# 音声コール（声・ナレーション）の挿入箇所 調査と提案（2026-11-20）

## 結論

現時点で、ファイナル・ペア発表・ルーザーズ切替などに「声で盛り上げる」音声コールを挿入する予定は、実装・確認できる範囲では定義されていない。音声Cueとして存在するのはBGMや衝撃音・カード開示音などの効果音で、録音ボイス、ナレーション、実況、チーム名の読み上げは見つからなかった。

設計資料は、会場の司会や歓声が入る余白として無音を意図的に使い、司会者が進行に合わせて止めたり進めたりすることを想定している。一方、既存のリハーサルレビューでは「観客向けナレーションや案内はない」と課題としている。つまり現在の方針は「録音ボイスを再生する」より「会場の司会に任せる」状態であり、システム音声の挿入箇所や原稿はまだ決まっていない。

## 現在の「声」と音声機能の状況

| 項目 | 現状 |
|---|---|
| 録音ナレーション／アナウンサー音声 | 音声ファイル・再生Cue・再生箇所とも確認できない |
| チーム名・参加者名の読み上げ | 実装なし。画面表示のみ |
| ファイナル／セミファイナルの音声 | 文字のコールアウトと効果音Cueはある。声の台詞やボイス素材はない。効果音素材にも欠落がある |
| ルーザーズ切替の音声 | “LOSERS”のタイトル演出と効果音Cueはある。声の台詞・素材はない。該当効果音ファイルもない |
| ペア発表の音声 | ペア発表BGMとカード・衝突効果音はある。ペア名を呼ぶ声や「チーム決定」の声はない |
| 会場司会 | 設計上は司会の声や歓声を活かす余白が想定される。ただし、システムとの音量ダッキングや司会タイミング連携はない |
| 音声設定 | 場面別ボイス、ボイス音量、読み上げON/OFF、台詞差し替えの運営設定は見当たらない |

注：ここではソースコード・素材名・設計文書を確認した。既存MP3を実際に聴き、音楽の中に声が含まれるかまでは判定していない。少なくともシステムが「声」として個別に扱い、台詞を同期再生する設定はない。

## 場面ごとの挿入候補

| 優先度 | 場面 | 現在の表示・演出 | 声を入れる案 | 判断・注意 |
|---|---|---|---|---|
| 高 | ペア発表の開始 | 抽選・カード公開・ペア発表BGM | 「運命の組み合わせが決まる。ペア発表、スタート！」 | 一度だけの短い導入が効果的。毎ペアで同じ煽りを繰り返すと長くなるため避ける |
| 高 | ペア確定の瞬間 | 2枚のカードが合流し、チーム名が表示される | 「〇〇と〇〇、チーム結成！」またはチーム名だけコール | ここが画と意味が最も合う。参加人数が多い場合は全組読み上げを任意／短縮可能にする。名前読み上げの誤読・読み方登録も考慮 |
| 高 | ルーザーズへ初めて切り替わる時 | LOSERSタイトルからルーザーズ表へ切替 | 「ここからは、一度の敗北も許されない。ルーザーズ、開幕！」 | 大きな章転換なので声の効果が高い。毎回の回戦ではなく、初回の切替だけにする。敗者復活のルール説明を短く添える選択肢も有効 |
| 高 | グランドファイナル第1戦 | FINALのVSコールアウト | 「優勝を懸けた、グランドファイナル！」 | ダブルエリミネーションでは第1戦の結果次第でリセット戦がある。常に「これが最後」とは言わない |
| 高 | リセット決勝 | FINAL → AGAIN表示 | 「決着は持ち越された。王者を決める、ファイナル・アゲイン！」 | 稀な特別シーンなので専用ボイスの価値が高い。第1戦と異なる声・間・音楽の盛り上げを使う |
| 高 | 優勝決定・CHAMPION | 優勝者の登場演出 | 「優勝は、〇〇チーム！」 | 最も明確なボイスコール候補。チーム名の読み方を登録できるようにし、読み上げ終了後に歓声・余韻を残す |
| 中 | 試合直前のVS | 対戦カード、台・回戦表示 | 「台1、第〇試合。〇〇 対 〇〇！」 | 大会中に何度も繰り返すので、全試合で鳴らすと騒がしい。司会用の任意コールか、観客が見失いやすい会場だけで有効化するのがよい |
| 中 | 勝者確定・WINNER | 勝者の写真・名前、ブラケット進出 | 「勝者、〇〇！」 | 勝者名の読み上げは理解を助ける。次の試合の案内まで一息に読まず、画面上の進出先が分かる間を確保する |
| 中 | 準決勝相当の山場 | SEMIFINAL表示 | 「勝てば決勝へ。〇〇 対 〇〇！」 | 現行の“SEMIFINAL”判定は回戦数ベースで、すべての大会形式で文字どおり準決勝とは限らない。声で「準決勝」と断言する前に、残りチーム数・進出条件に基づく判定確認が必要 |
| 中 | 抽選・大会開始 | 受付終了・Draw開始 | 「エントリー締切。ここから、対戦チームが決まる！」 | 開始時の短い導入向き。説明を長くせず映像に任せる |
| 低／任意 | 各回戦・進行中 | ブラケット更新・次試合待機 | 回戦名、進出先、次に始まる試合を短く案内 | 操作・演出・会場MCと重なりやすい。常時自動ナレーションにせず、必要時の案内モードがよい |
| 任意 | 3位・2位・表彰台 | 順位発表・表彰 | 「第3位は…」「準優勝は…」「そして優勝は…」 | 表彰進行と相性がよい。司会者が話す場合はシステム音声を鳴らさない運用が必要 |

## 声を入れるなら推奨する設計

1. **全画面を喋らせず、節目だけに絞る。** ペア発表開始、ルーザーズ初回切替、決勝、リセット戦、優勝を基本セットにする。試合前・勝者コールは会場やモードに応じて追加する。
2. **司会の声と録音ボイスを同時に鳴らさない。** 「会場MCモード（システムボイスOFF）」と「自動ショーモード（システムボイスON）」を選べる設計がよい。自動ショーでは声の直前にBGMを少し下げ、声の後に戻す。
3. **台詞は短く、表示内容と一致させる。** 画面が「FINAL AGAIN」なら音声もリセット戦であると伝える。決勝第1戦を必ず最終戦と誤解させる表現は避ける。
4. **動的な名前は固定録音だけに頼らない。** チーム名・人名の発音や読み方を登録する欄を設ける。録音音声にする場合は、固定の短い煽り＋運営者の生コール、または読み上げ機能を組み合わせる。
5. **長さと再生条件を運営画面で管理する。** 場面ごとの音声プレビュー、ON/OFF、音量、冒頭位置、再生済み状態、読み上げ内容の確認、スキップを用意する。欠損・自動再生拒否は運営者に見えるようにする。
6. **無音も残す。** ペア名発表後や優勝者登場前に短い間を置くと、会場の歓声や司会の声が活きる。声を連続で重ねず、重要な声の前後に余白を作る。

## まず決めるとよい最小ボイス台本

- ペア発表開始：「運命の組み合わせが決まる。ペア発表、スタート！」
- ペア確定：「［チーム名］、チーム結成！」
- ルーザーズ初回：「ここからは、一度の敗北も許されない。ルーザーズ、開幕！」
- 決勝第1戦：「優勝を懸けた、グランドファイナル！」
- リセット戦：「決着は持ち越された。ファイナル・アゲイン！」
- 優勝：「優勝は、［チーム名］！」

これは今回の確認を基にした新規提案で、既存の実装済み／確定済み台本ではない。実装や収録は行っていない。
