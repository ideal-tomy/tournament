ただし現在、

- Adminが表示されないことがある
- Cloudflare用Workerが複数存在している
- どのWorkerが現在の正しい環境なのか分かりにくい
- deploy経路が安定していない
- 公開環境で「スマホ撮影 → 登録 → ペア発表 → 大会 → 優勝」まで通せるか把握できていない

という状態です。

今回は新機能追加・演出強化・UIデザイン改善を行う前に、

**現在の構成を調査し、Cloudflare上に1つの正しいリハーサル環境を作り、参加者登録からCHAMPIONまで公開環境で通せる状態に整理してください。**

# 10. Secrets

以下のようなSecretが必要な場合、
Worker Secretsとして管理してください。

ブラウザbundleへ埋め込まないでください。

禁止：

- VITE_ADMIN_API_TOKEN
- VITE_DISPLAY_API_TOKEN
- SecretをHTMLへ埋め込む
- Secretをquery parameterへ入れる

現在のauth/session実装を調査し、
安全な構成を維持してください。

Secret値そのものをログへ出力しないでください。
