トーナメントの演出を、localhostではなく公開URLから実機確認できるようにしたいです。

目的は本番運用ではなく、演出・UI・アニメーションの確認です。

既存の

- /local-rehearsal
- /show-preview

を確認し、既存Admin／Display／Supabase／Cloudflare APIの本番処理を壊さずに、演出確認専用の公開Previewを作成してください。

## 目的

公開URLをPC・スマホ・会場モニターなどから開き、

- Draw
- VS
- Result
- Bracket advance
- NEXT MATCH
- Champion

などの演出をサンプルデータで一通り確認できる状態にする。

## 方針

このPreviewでは本番DB更新を行わない。

- D1への書込み不要
- R2への書込み不要
- Admin API Tokenをブラウザへ埋め込まない
- DISPLAY_API_TOKENもブラウザbundleへ埋め込まない
- Supabase本番データを変更しない

サンプル／fixtureデータだけで演出を確認できる構成を優先する。

## 確認してほしいこと

1. 現在の /local-rehearsal と /show-preview の実装
2. どちらを公開Previewのベースにするのが安全か
3. Vite buildで公開可能か
4. VercelまたはCloudflareで公開する場合の最小変更
5. 公開Preview専用URLの構成
6. PC / SP / 1920×1080表示での確認方法

まず既存構成を調査し、最小変更の実装計画を提示してください。

既存Admin／Displayの本番処理は変更しないでください。
