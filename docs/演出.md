# トーナメント演出素材の整理・実装方針

- 作成日: 2026-08-07
- 対象: `public/演出用仮置き/` にある仮素材の整理と、Display の抽選・対戦・勝敗演出への組み込み
- この文書の目的: 素材を先に確定し、その後に演出を小さく組み立てて検証できる状態にする

## 1. やりたいことの理解

既存資料から、目指しているものは単なる画像差し替えではなく、ダーツ大会の進行を一本の映像作品のように見せる演出である。

特に今回の素材は、次の3つの場面で利用する想定と理解した。

1. **チーム編成・抽選（full版）**
   - 参加者カードを見せる
   - カードを裏返す
   - ダーツが飛来してカードへ刺さる
   - 衝撃、穴、煙、リングなどを重ねる
   - カードを表に返して参加者を公開する
   - 公開順にチーム化し、トーナメント表へ配置する
2. **対戦カード（VS）**
   - これから戦う2チームを左右に表示する
   - 大会区分（Winners / Losers / Grand Final）を明確にする
   - 対戦カードは自動で閉じず、Admin操作まで保持する
3. **勝敗結果**
   - 勝者を150%へ拡大する
   - 敗者を75%へ縮小し、周辺を暗転する
   - 勝者を明るく見せ、花吹雪を重ねる
   - 完了後にブラケットへ戻る

演出の上位ルールは既存の要件定義を維持する。

- 組み合わせは演出開始前に確定し、演出内で抽選しない
- Adminが状態を更新し、Displayは状態を購読して描画する
- 1920×1080を基準にし、実画面には等比率で拡大縮小する
- `full` / `short` / `lite` の各モードで同じ確定データを再生する
- 大会名、参加者、広告、テーマなど大会ごとに変わる値を素材へ焼き込まない

## 4. 素材整理のルール

### 4.1 ファイル形式

- 大きな全面背景は原則 WebP。画質を見ながら容量を抑える
- 透過が必要なエフェクト、枠、ダーツはPNGを維持する
- カード表裏は透過と画質に問題がなければWebPに変換する
- 音声はMP3。再生開始のずれを避けるため、先頭の無音を除去する
- 変換後も `演出用仮置き` の原本は、移行完了までは削除しない

### 4.2 画像の調整

- 透明余白を確認し、アニメーションの座標基準が画像中心と一致するようにする
- 同じ衝撃点へ重ねる素材は、キャンバス中心と着弾中心を揃える
- 枠素材は文字や顔写真を含めず、HTMLで内容を差し込める状態にする
- 1920×1080上で100%表示したスクリーンショットを取り、ぼけ・見切れ・余白を確認する
- ファイル名は小文字の英数字とハイフンに統一し、日本語名を実装から参照しない

### 4.3 実装からの参照

素材URLを各コンポーネントへ直書きせず、例えば `src/lib/tournamentEffects.ts` のような1ファイルへ集約する。

```ts
export const TOURNAMENT_EFFECTS = {
  cardBack: '/tournament-effects/cards/card-back.webp',
  cardFront: '/tournament-effects/cards/card-front.webp',
  dart: '/tournament-effects/darts/dart-main.png',
  impactFlash: '/tournament-effects/effects/impact-flash.png',
} as const;
```

プリロード対象もこの定義から作り、素材の名称変更時に修正箇所が増えないようにする。

## 5. 実装の進め方

### Step 1: 素材を目視確認して対応を確定する

1. 仮素材15点の一覧画像を作る
2. `爆発.png` と `爆発02.png` の役割を決める
3. `スモークバック.png` を大会背景に使えるか確認する
4. VSと花吹雪を正式構成へ追加するか決める
5. 不足素材の作成範囲を決める

完了条件: 上の対応表から「暫定」「要確認」がなくなる。

### Step 2: ディレクトリ作成・変換・軽量化

1. `public/tournament-effects/` 以下を作成する
2. 原本をコピーして英語名へ変更する
3. 背景・カードを必要に応じてWebPへ変換する
4. 透明余白と着弾中心を調整する
5. 全ファイルをブラウザで単体表示して透過・解像度を確認する

完了条件: すべての確定素材が目標パスにあり、壊れた画像や意図しない背景色がない。

### Step 3: 素材カタログとプリロードを実装する

1. 素材パスをTypeScript定数へ集約する
2. Display開始前に必要素材をプリロードする
3. 読み込み失敗時は演出全体を止めず、代替表示へ落とす
4. 音声はユーザー操作後に再生可能にする

完了条件: 初回再生でも画像が途中から現れず、ブラウザのコンソールに404が出ない。

### Step 4: 抽選演出を一人分だけ試作する

最初から参加者全員のループを作らず、1枚のカードで次の順を完成させる。

```text
カード裏を表示
→ ダーツと軌跡が飛来
→ 着弾時に flash + ring + cloud + debris + impact-mark
→ カードをY軸回転
→ 表面へ参加者写真・名前を表示
→ team-confirm音
```

レイヤー順の目安:

```text
背景
→ カード
→ 参加者写真・名前
→ impact-mark
→ ダーツ
→ cloud / debris
→ flash / ring
→ 画面全体の光
```

アニメーションの制御は1本のGSAPタイムラインに集約する。Reactのmount/unmountを演出の時間制御に使わず、必要なDOMは先に配置して `opacity` と `transform` で制御する。これは既存の試合確定演出で発生したref接続とタイムラインの競合を繰り返さないためである。

完了条件: 同じ操作を10回繰り返しても、ダーツ・衝撃・カード反転の順序が変わらない。

### Step 5: 確定済みの公開順へ展開する

1. `draw_sessions.reveal_order` を受け取る
2. Step 4の1人分タイムラインを順番に再生する
3. 奇数・偶数（またはチーム人数単位）でチーム表示へまとめる
4. 完成チームをブラケットの確定位置へ移動させる
5. `short` への切り替えとスキップを実装する

参加者数に比例して尺が長くなるため、1人あたりの秒数を設定可能にし、開始前に総時間を表示する。

### Step 6: VS・勝敗演出へ素材を反映する

- `VsCardScene.tsx`: 画像枠、名前プレート、チームプレート、VS画像、背景を適用する
- `ResultScene.tsx`: 仮の `/images/test_mv.webm` 依存を外し、正式な花吹雪素材へ置き換える
- Winners / Losers / Grand Final のテーマ色を素材の発光色と合わせる
- 対戦カードの手動クローズと「操作待ち」表示は維持する

完了条件: VS画面、試合中画面、結果画面の大会区分が1秒以内に識別でき、勝敗演出後に正しくブラケットへ戻る。

## 6. 演出タイムラインのたたき台

ダーツ着弾からカード公開までの一人分は、まず2.5〜3.0秒程度で試作する。

| 時刻 | 演出 |
|---:|---|
| 0.00s | カード裏面を表示 |
| 0.20s | ダーツ飛来音、ダーツと軌跡を画面外から移動 |
| 0.70s | 着弾。短い画面揺れ、フラッシュ、穴を表示 |
| 0.72s | リングを拡大、煙と破片を遅れて展開 |
| 1.10s | ダーツと強いフラッシュをフェード |
| 1.25s | カードをY軸方向へ反転開始 |
| 1.55s | 裏面から表面へ切り替え |
| 1.85s | 写真、名前、枠を表示 |
| 2.10s | チーム確定音、軽い発光 |
| 2.70s | 次の参加者、またはチーム紹介へ移行 |

この数値は固定仕様ではなく、最初の試作を目視調整するための開始値とする。

## 7. テスト・確認項目

### 素材

- [ ] 全URLが200で取得できる
- [ ] 透過PNGの周囲に白・黒の縁がない
- [ ] カード表裏の外形と回転中心が一致する
- [ ] ダーツ、穴、リング、煙の着弾中心が一致する
- [ ] 1920×1080で素材がぼけない
- [ ] 日本語ファイル名を実装コードから参照していない

### 動作

- [ ] 初回再生と2回目以降でタイミングが変わらない
- [ ] リロード時に抽選結果が変わらない
- [ ] 演出の途中でshort版へ切り替えられる
- [ ] `lite` で静止画・CSS中心の代替表示になる
- [ ] 音声が鳴らない環境でも演出が停止しない
- [ ] 16人、32人でメモリ使用量とフレームレートを確認する
- [ ] Adminのスキップ、手動クローズ、1手戻すが正常に動く

### 見た目

- [ ] 着弾前に穴や爆発が見えない
- [ ] 衝撃の主役が一度だけ現れる
- [ ] カード反転中に表裏が同時に読めない
- [ ] 写真・名前・チーム名が枠内に収まる
- [ ] エフェクトが人物の顔や名前を長時間隠さない

## 8. 確定した判断と次の作業

次の判断は2026-08-07に確定し、素材へ反映済み。

1. `VS.png` と `花吹雪.png` を正式構成へ追加する
2. `爆発02.png` は不採用とし、仮置きフォルダから削除する
3. 不足していた背景、火花、破片、音声を新規作成する
4. `スモークバック.png` を `tournament-bg.webp` として採用する

次は、**単体プレビュー → 一人分の抽選演出 → 全員への展開 → VS/勝敗画面への反映**の順で進める。
