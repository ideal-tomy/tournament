# 演出改善の実装プラン

日付：2026-11-28  
対象：会場 Display のペア発表、勝ち上がり、対戦コール  
状態：実装済み。進行の真実源（`bracket_snapshot`）とシーンの真実源（`event_state`）は変えていない。

## 直すこと

1. ペア発表の最後、チーム一覧がカードの途中で止まり、周回しない。
2. ペア発表の1人目だけ、ダーツが刺さるところから顔が出るまでがかくつく。
3. セミファイナル、ファイナル、ファイナル・アゲインの声がなく、通常対戦の呼び込みと FIGHT も未接続。
4. 勝ち上がり演出で、まだそのチームの演出前なのに、次の枠への線が光り、顔写真が入っている。
5. 線が伸びて勝ちチームが出た瞬間、その枠だけに寄る。

## 今回は直さない

| 現象 | 理由 |
|---|---|
| 自分のPCでは鳴っているBGMが、別の会場端末だけ途中から無音 | こちらの再生では再現しない。別端末のコンソールは `ERR_NAME_NOT_RESOLVED` で、workers.dev の名前解決に失敗している。曲の差し替え処理を先に変えない |
| 運営と会場に出る「通信できませんでした」 | 同じ名前解決の失敗を、受付向けの文言で出している。通信そのものの不具合ではない |
| `/favicon.ico` の404 | 表示にも進行にも影響しない |
| ルーザーズ開幕の声 | 添付の5本に該当ファイルがない。`losers-open.mp3` の404は残る |

## 1. チーム一覧を周回に戻す

### 現状

`TEAMS CONFIRMED` は、同じページを2組並べて継ぎ目を隠す形のままである。動かし方だけが1回の途中止めになっている。

- 画面は4組で1ページ。20組なら5ページで、1周は約50秒。
- 終了時刻の計算は8組で1画面、20組前後は2周、という別の数え方。
- `DrawStage` はその短い持ち時間で移動距離を切る。20組だと約1.4ページで、ページの境目に止まる。
- 繰り返さない。運営が「ブラケットを表示」を押すまで、左右のカードが切れた画で残る。

終了時刻に絵を合わせるために縮めた結果で、止まった位置がページの切れ目になっている。

### 実装

- トラックは1ページ幅ずつ等速で送る。2組並べた幅のちょうど半分まで送ったら先頭へ戻し、見ているあいだは繰り返す。
- シーンの終了時刻は今の `estimateDrawDurationMs` のままにする。周回はそこで止め、進行の解禁時刻は変えない。
- ページ数は画面と同じ「4組で1ページ」に揃える。`estimateTeamSummaryMs` の「8組で1画面」は、この帯の持ち時間を決めるためだけに残すか、帯の秒数と一致する値へ直す。どちらでも、移動距離の計算には使わない。
- 1ページのときも、切れた位置で止めない。

### 触るファイル

- `src/features/presentation/scenes/DrawStage.tsx`
- `src/features/presentation/drawAnimationTiming.ts`
- 帯の見た目は `src/checkin/draw.css` の `.draw-team-page`（幅は `100vw`）

### 確認

20組で、ページの境目を越えてもカードが切れず、少なくとも2周まで同じ速度で流れる。1組、4組、5組でも端で止まらない。終了後に運営の「ブラケットを表示」が、今と同じタイミングで押せる。

## 2. 1人目のカードを、2人目以降と同じ手順で出す

### 現状

2人目以降の「ダーツが刺さる、カードが返る、顔が出る」と、1人目の手順は同じタイムラインである。1人目だけ、シーンを出した瞬間にダーツ、閃光、カードのデコードが重なる。顔写真は `preparePortraits` で事前に展開しているが、効果画像は展開完了を待たない。導入の「チーム編成」は約1.2秒で、読み込み完了も見ていない。

### 実装

- ペア発表に入ったら、最初のカードを動かす前に、その手順で使う画像（カード表裏、ダーツ、閃光、衝撃、リング）のデコードを終える。
- 待っているあいだは、待機画面からカード台への短いトランジションにする。読み込みが終わってから、1人目を今と同じ秒数で再生する。
- 1人目の動きの中身、2人目以降の間隔、演出全体の終了時刻の意味は変えない。デコードにかかった待ちは、サーバー側の終了時刻より演出が遅れない範囲に上限を置く。上限を超えたら、未完了でも1人目を始める。
- すでにキャッシュがある2回目以降は、待ちを足さない。

### 触るファイル

- `src/features/presentation/scenes/DrawStage.tsx`
- `src/checkin/preloadPresentationAssets.ts`
- `src/lib/tournamentEffects.ts` の画像URL

### 確認

キャッシュを消した状態で、1人目が2人目と同じ順で、途中のコマ落ちなく終わる。2人目以降の間隔は今と同じ。キャッシュ済みでも、不要な長い暗転がない。

## 3. アナウンス音声5本を、今のコール位置へ付ける

置き場所は `public/演出用仮置き/アナウンス音声5本セット`。ビルドが配るファイルは `vite.checkin.config.ts` のコピー一覧に足し、`src/lib/tournamentEffects.ts` のCueから参照する。仮置きフォルダ自体は公開配信に移さない。

## 4. 勝ち上がりの線と顔は、そのチームの演出で出す

### 現状

添付の確認画面（`ウイナーズ 1回戦 · 3/6 · team-5`）では、今の演出が仮ペア05側でも、仮ペア07から次の枠への線がすでに光り、次の枠に両方の顔が入っている。

勝ち上がり画面は、演出中の1試合ではなく、保存済みの表全体（`state.bracket`、確認画面ではそのステップの `after`）を描く。`isConnectorHighlighted` は、試合が終了して勝者が次の枠に入っていれば線を光らせる。顔もその枠のスロットにそのまま出る。アニメーションが隠すのは、今動かしている1スロットだけで、開始2秒後に出す。もう一方の線と顔は最初から見える。

勝敗の保存が演出より先でも、進行上は正しい。ブラケットの計算結果は変えない。変えるのは、演出中の見せ方だけである。

### 実装

- 演出中の表は、次の2つだけを「進んだ」状態で描く。
  - この演出より前に、会場で勝ち上がり演出が終わっている試合。
  - 今再生している1試合。こちらの線は今どおり0.5秒から1.5秒で伸び、顔は2秒で出す。
- 勝敗は保存済みでも、まだその演出が始まっていない試合は、線を光らせず、次の枠に顔を入れない。元の試合枠の勝敗表示は今のままでよい。
- 本番は、演出が終わった試合IDを表示用の状態として持つ。確認画面 `/venue-check` は、今のステップより前に再生し終わった試合を、同じ条件で出す。
- 線の伸びと顔の出現が終わったあと、その枠だけへ寄る。今は送り元と行き先をまとめて寄っている（`frameViewBox([source, dest])`）。寄る対象を行き先の枠にし、全体へ引く現在の6秒の流れは残す。
- ルーザーズの勝ち上がりも同じ条件にする。こちらは線を描かず、進出先の顔だけが先に出ないようにする。

### 触るファイル

- `src/checkin/AnimatedBracketAdvance.tsx`
- `src/features/bracket/BracketView.tsx`
- `src/features/bracket/layout.ts` の `isConnectorHighlighted` を、演出中だけ上書きできる形にする
- `src/features/bracket/LosersColumnBoard.tsx`
- `src/checkin/venueAdvance.ts` と `src/checkin/VenueCheckPage.tsx`（確認画面の既出試合）
- 本番で「演出が終わった試合」を持つなら `cloudflare/checkin/src/flow.ts`。スナップショットの勝敗計算は変えない

### 確認

隣り合う2試合の勝敗が両方保存された状態で、先に演出する側だけ線が伸び、顔がそのタイミングで入る。もう一方は、自分の演出が始まるまで線が光らず、次の枠に顔がない。演出が終わった試合は、次の試合の演出中も線と顔が残る。不戦勝、進出先がない試合、ルーザーズ、決勝で、線の接続位置がずれない。

## 実装順

1. チーム一覧の周回。見た目の切れが一番分かり、進行時刻に触れずに直せる。
2. 1人目のデコード待ち。ペア発表の中だけで完結する。
3. 音声5本の接続と、無いファイルの先読み停止。
4. 勝ち上がりの線・顔・寄り。表の見せ方なので、確認画面と本番の両方を見る。

各項目のあとで、既存の `npm test` と、その項目が触った画面の確認をする。4のあとだけ、ウィナーズとルーザーズの勝ち上がりを連続で再生する。

## 完了の見方

- 20組のチーム一覧が、カードの途中で止まらず周回する。
- キャッシュなしの1人目が、ダーツ、反転、顔の順で2人目以降と同じに見える。
- 添付5本が上の表の場面で鳴り、無い4ファイルの404がコンソールに出ない。
- 未演出の勝利は線も次枠の顔も出さず、演出した勝利だけが残る。顔が出た枠へ寄る。
- ペア発表の終了時刻、運営ボタンが押せる時刻、ブラケットの勝敗計算は、この変更の前と同じである。
