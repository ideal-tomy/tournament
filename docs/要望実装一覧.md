## C. ルーザー試合の進行（連戦・間隔）

### C-1. ルーザー 1 回戦後の連戦をやめる ─ 🔲

- **要望**: WINNER 側と同様、**試合間隔を平等に**。左から単純に次を出すのではなく、休息・回戦の消化順を守る。
- **想定原因**:
  1. **章の選択**: ルーザー 1 回戦が奇数試合などで、1 試合終了後に **2 回戦だけ Ready** になり、`getChapterMatches` の `pickLowest(loserReady)` が 2 回戦を先に返す（1 回戦の片側待ち枠は `readyPlayable` に入らない）。
  2. **1 台 `nextMatch()`**: `getChapterMatches(data)[0]` のみ使用。**`restingTeamIds` / `orderCourtMatches` を通していない**（複数台の `getCourtFillMatches` とは別ルート）。
- **改善案**:
  - `tiers.ts` の `getChapterMatches`: ルーザーで **回 R に未完了試合が残る間は R+1 を章に出さない**（ウィナー早期の回待ちに近いガード）。
  - `flow.ts` の `nextMatch()`: `getCourtFillMatches`＋直前勝敗チームを `restingTeamIds` に渡す。
  - `progression.test.ts` にルーザー奇数 1 回戦後のケースを追加。
- **確認時のメモ**: 1 台運用か複数台か、連戦が「同一チーム続けて」か「回が飛ぶ」かを記録する。

### D-2. フォントサイズ（WINNER タイトル級） ─ 🔲

### D-3. ファイナルバトル「アゲイン」の段階表示 ─ 🔲

- **要望**:
  1. 先に **「ファイナルバトル」** を表示（他コールアウトと同様の入り）。
  2. **「アゲイン」** を **右から勢いよくスライドイン**、**音とともに激しく**表示。
- **実装方針**:
  - `callout === 'final-again'` のとき DOM を2要素（`.vsb-callout-base` / `.vsb-callout-again`）に分割。
  - GSAP: ベースは現行 0.15s 付近、`finalBattle` 音。アゲインは 0.9〜1.1s 付近で `x` スライド + `finalBattleAgain` 音（必要なら短いフラッシュ／シェイク）。
  - `prefers-reduced-motion` 時は両方まとめて静かに表示。
- **テスト**: `VsBoard.test.tsx` を分割文言・クラスに合わせて更新。
- **音声**: `tournamentEffects.ts` の `final-battle.mp3` / `final-battle-again.mp3`。未配置時は 404 無音（`現状差分.md` 参照）— ファイル追加は別判断。
